# IPTV 使用说明

本目录用于管理 IPTV 频道列表，并生成带 HTTP 代理的 m3u8 播放列表。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `base.m3u8` | 基准频道列表，包含原始 `rtp://` / `rtsp://` 地址（源数据，不要手改输出格式） |
| `build.py` | 基于 `base.m3u8` 生成带代理前缀的播放列表 |
| `me.m3u8` | 给自己用的列表（南边代理 `192.168.10.30:5140`） |
| `parents.m3u8` | 给父母用的列表（北边代理 `192.168.1.101:5140`） |

## 生成播放列表

编辑 `build.py` 顶部的配置（可直接修改）：

```python
BASE_FILE = "base.m3u8"
PROXIES = {
    "me.m3u8": "http://192.168.10.30:5140/",       # 自己
    "parents.m3u8": "http://192.168.1.101:5140/",  # 父母
}
```

运行：

```bash
cd iptv
python3 build.py
```

脚本会把 `base.m3u8` 中所有地址加上对应代理前缀：

- `rtp://239.3.1.129:8008` → `http://192.168.10.30:5140/rtp/239.3.1.129:8008`
- `rtsp://61.135.88.136/TVOD/...` → `http://192.168.10.30:5140/rtsp/61.135.88.136/TVOD/...`

> 新增一份代理列表，只需在 `PROXIES` 里加一行 `{输出文件: 代理前缀}` 即可，主循环会自动遍历生成。
